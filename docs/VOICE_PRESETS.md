# Fish 音色批量管理

在面板依次点“声音 → Fish 音色 → 新增 / 管理 → 批量管理”。默认收起，名单只保存在原 AutoJs6 的本地存储，不随更新上传到 GitHub。

## 粘贴导入

支持以下格式，示例 ID 均为虚构，请换成自己的有效音色 ID。

每行一个 ID：

```text
voice-a
voice-b
```

名称与 ID 用英文逗号、中文逗号或 Tab 分隔：

```text
明朗男声,voice-a
温柔女声,voice-b
```

JSON 数组可混用 ID 字符串与 name/id 对象：

```json
[
  {"name": "明朗男声", "id": "voice-a"},
  "voice-b"
]
```

先点“预览导入”，核对新增、改名、重复与无效数量，再点“导入有效条目”。无效行跳过并显示原因，错误提示不回显误粘贴的 API Key。空行和以 # 开头的注释忽略，同批重复保留第一条。一次最多 2000 条、文本最多 200000 字符，更多可分批。

默认合并到现有列表，已有 ID 跳过并保留名称；勾选“同 ID 时更新已有名称”才会按导入的非空名称改名，空名称不覆盖旧名称。预览后若文本、选项或现有名单变化，必须重新预览。

## 多选管理

勾选要管理的候选，或全选/取消全选。

- 删除所选：先确认数量；只删除本地候选，不删除 Fish 平台音色。若包含当前选中 ID，会清空选择并提示重新选声音，正在播放的一段保持原音色。
- 批量命名：填 1—28 字符前缀，按当前名单顺序命名为“前缀 1、前缀 2…”，确认后执行；不改 ID。
- 撤销最近一次名单操作：恢复前一次名单与选中 ID，支持重启后撤销。只保留最近一次备份；后续添加/保存、导入、删除或改名会更新这份备份。

原有单个音色添加、改名和下拉选择仍可用。切换只对下一次回答生效，不自动将系统模式改成 Fish，也不重新播放当前回答。

目前提供粘贴导入，不需要上传名单或选择手机文件。若标准存储记录异常，不自动覆盖，会保留原记录供核对。
