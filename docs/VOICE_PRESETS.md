# Fish 音色

声音 → Fish 音色，入口只有“新增”“管理”“试听”。Key 在“大脑连接 → 设置”填写。名单保存在手机，更新不会清空，也不会上传到 GitHub。

## 新增

点击“新增”，名称与 ID 两行总是空白。填写后点“保存音色”，保存并选用这个声音。进入新增不会改变当前已选声音；未保存草稿不会覆盖它。

## 批量导入

新增区下方点“批量导入”，粘贴即可。输入停止约 650ms 后自动识别保存，没有预览、导入确认、覆盖选项。

- 每个 ID 是 32 位英文字母/数字，多个可连续粘贴，或用空格、换行、逗号分隔。
- 名字跟在 ID 前面，自动一名一 ID 配对，名字和 ID 分两行也可；英文名字与 ID 用空格分开。
- 无名自动命名。相同 ID 跳过、保留原名称，不覆盖已选声音。
- 不完整内容提示待补全；不会自动导入短 ID。修改粘贴内容不会删除已导入项，重复粘贴不会重复添加。

示例 ID 为虚构：

```text
温柔男声 0123456789abcdef0123456789abcdef
快乐少年 fedcba9876543210fedcba9876543210
```

## 管理

勾选音色，可“全选 / 取消全选”“改名”“删除”。一个音色改名时直接输入名称；多个音色改名时输入前缀，自动编号。只有点改名才出现名称输入。

删除需确认，只删手机名单，不删 Fish 平台声音。删除当前声音会清空当前选择；正在播放的声音不变。存在备份时显示“撤销上次操作”，可恢复最近一次保存、导入、删除或改名；重复粘贴不会覆盖撤销备份。
