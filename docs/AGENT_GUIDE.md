# 手机 Agent 使用说明

更新：原启动器检查更新 → 下载安装 → 重启。沿用 AutoJs6 的 jarvis_config_v2、Key、音色与 /sdcard/Jarvis/Memory/，无需再次导入程序。启动器保持 2.0。

## 语音与图像

默认单击蓝狐启动 MiMo 中转站录音转写，模型 mimo-v2.5-asr，沿用原大脑地址和 Key；不是鱼音的合成接口。安静约 0.9 秒结束，再点小人也可结束。录音和转写不弹卡片，可双击小人取消本次听写并打开文字输入；已开始上传的请求不能撤回。音频只在内存中组 WAV，不落盘。未检测到人声不上传。

更多设置保留听写测试。若前台可录、桌面无声，需检查宿主麦克风及后台运行；Android 16 可能限制后台收音。软件不会伪装系统识别成功，也不会自动安装或切换收费服务。用户旧版报告 HTTP 400。默认改标准 Base64 最小请求，可在更多设置的听写方式下选 MiMo Data URL；不自动重试录音或切到新服务。400 原因会显示脱敏后的服务端信息；真实网关兼容性需手机试用。

说“看看当前屏幕”或点识图按钮，执行端才真正截图并将图片交给当前模型。可以在连接设置填独立视觉模型；留空沿用主模型。系统屏幕共享授权必须由你操作，同次共享会话内复用授权，退出或在更多设置停止屏幕共享时释放。只在用户触发任务时取画面，不连续录像；系统撤销/结束会话后需重新同意。受保护画面可能黑屏，模型/中转站拒绝图像时会报告失败。

## 文件与界面

默认工作目录 /sdcard/Jarvis/Workspace/。更多设置中的 Agent 执行默认启用；一键权限入口按缺失项引导麦克风、悬浮、无障碍、通知、所有文件访问，安卓仍要求逐项确认。

可说“在工作目录新建项目说明.txt”“读取并修改 /sdcard/Download/笔记.md”。支持共享存储的 UTF-8 文本新增/改写、目录列出、单文件回收和恢复；覆盖前读取并核对哈希，修改保留备份，恢复遇到后来修改会拒绝覆盖。历史在 /sdcard/Jarvis/AgentData/history/。不开放 shell，保护 Jarvis 程序及执行历史、Android/data 与 obb；不能绕过应用私有目录、Root/系统分区权限。不是所有二进制文件编辑器。

可说“打开微信”“点击某个可见控件”“输入这段草稿”。通过无障碍可见节点操作，遇到歧义会要求补充目标。最多连续八步，可在主面板停止任务。没有无障碍时会明确失败，不假称已执行。草稿提供独立复制，通知存在时可跳对应聊天，其他情况打开对应应用；最终发送、支付等由你确认。

图片、任务读取的相关文字、对话和记忆会发送到你配置的中转站。不把 API Key 写进公共包、日志或记忆；文件内指令与截图内容不作为新授权。

## 每日上下文与记忆

按手机本地日期记录 /sdcard/Jarvis/Memory/Daily/YYYY-MM-DD.jsonl，另有可供 Obsidian 浏览的 .md。重启恢复当天对话；模型窗口有限时自动装入近期片段，较早内容可由助手搜索，不承诺整天无限文本同时放入一次请求。

次日空闲时整理前一日；应用关闭时无法定时运行，下次启动补做。大日记分段并保留进度，完成后当天不重复执行。每日整理会调用你的对话模型，按中转站计费；可在更多设置关闭。当前日明确偏好也可即时记录。

实际使用文件是 User_Persona.md 和 人际关系表.md。自动区域用 HTML 注释标记，区域外手工内容保留；不要删掉半个标记。Relationship_Graph.json 保存带日期与原话依据的关系，Collaboration_Memory.json 保存明确/推测偏好，Daily/*.summary.json 保存摘要与恢复记录。明确事实需用户原话支持；推测不升级为已确认设定，无法自行提升权限。同类新偏好可替换旧偏好，文件并发修改会停止覆盖并稍后重试。

## 会话与简化入口

单击小人直接听写，不再先恢复旧卡片；录音中再单击结束，双击打开文字输入并取消本次听写。录音只显示偷听，转写/任务只显示思考或工作，最终回答或明确失败才弹结果卡。长按小人或点卡片“历史”，第一项“最近回复”可一键找回；也可按日期选择最近 100 条消息，完整记录仍在磁盘并支持搜索。切换历史后续聊追加到所选日；选择今天返回当前日，不删除日记。

气泡移除“朗读/停声”，普通回答按自动朗读设置播放。点击“读屏”读取无障碍文字到输入卡供检查后发送，速度不依赖远端视觉模型；长按“读屏”才截图并发视觉模型，文字预览与看图片是不同路径。系统/受保护画面限制仍存在。

## 多 API 渠道和模型

大脑连接 → 设置：渠道下拉框切换，每个渠道保留 URL、Key、当前对话模型、ASR 模型、可选视觉模型与封装设置。任务/录音/整理进行时不能切换渠道。原配置自动成为“原有渠道”，沿用原 Key。渠道名单位于原 AutoJs6 storages，不进入程序更新包；不是云同步或系统加密保险库。

“新增渠道”打开留空的名称、接口地址、API Key、对话模型四栏，填写后保存，在渠道下拉框选择使用；每栏有固定标签，不影响原渠道。另点“批量导入”展开原粘贴框，停顿后自动导入，不切换当前渠道。支持 JSON 数组或 {"channels":[...]}，字段 name、url/base_url、key/api_key、model、models、asr_model、vision_model。也支持每组依次四行：名称、HTTPS 地址、Key、对话模型，组间空行；模型可以稍后补。同一 URL + Key 去重，不同 Key 分开。不要把含 Key 的文本提交到公开仓库。管理支持改名、确认删除；当前渠道须先切到其他渠道才能删除。

对话模型下拉选择保存的候选；手动填写后“保存候选”，或“获取模型列表”调用当前渠道 GET /v1/models。网关不支持列表时继续手填；列表包含不等于账号可调用。候选按渠道 ID 隔离。

“测试对话模型”调用当前对话模型并在按钮下持续显示结果；“测试听写模型（录音）”录一句真实声音，以 ASR 配置调用，结果在自己的区域显示，不转交对话模型。两者不会误用同一段文本问候测试。测试会正常使用配置中的接口，不保证免费。

模型空白、只返回思考、空对象或“暂无内容”占位不再显示为成功；格式错误最多修正一次，仍失败显示模型及原因。UI 操作失败会保留执行器错误，不虚构“已给文件传输助手发送”。目前仍由用户确认最终发送。


## 正文与播放修复

正文只展示自然文本，不展示 answer/emotion 等 JSON 字段、动作请求或 XML 工具片段。解析支持模型错误放入字符串内的真实换行与二次编码；无法修复时最多请求格式修正一次，仍无效则明确报失败。模型自己写的目录清单或 tool_result 不是本机执行证据，不能据此声称已检查或清理文件。

系统朗读出错时直接保留完整文字，不从头逐字重打。Fish 在尚未播放前失败可回退一次；已经播放后再失败不换声音重读本段。文字范围回调不倒退，重复开始/过期动画忽略。修复程序的重复路径不等于保证安卓引擎或音频服务从不中断；实机仍需验收。文件修改所用 content 保留原格式，不受回复清洗影响。

## preview15 修复分支（未发布）

脚本运行且 AutoJs6 通知服务已授权时，可接收微信、QQ、钉钉、小红书、抖音、B站实际推送到系统通知栏的文字；任务忙碌期间进入本机待处理队列。Agent 可用 notifications.recent 查询系统通知记录，不是微信或 QQ 全量聊天历史，也不保证进程被系统杀死期间能接收。通知与聊天内容属私人数据，不上传到公开仓库；分析通知仍会调用用户配置的模型中转站。

清理只针对 `/sdcard/Jarvis/App/` 内部确认不再使用的自身版本、旧临时更新下载和多余状态备份；保留本版和上一版供回退。微信下载目录里的手动 ZIP 不自动删除。

OPPO/Android 16 需要用户在系统中授权通知使用权、无障碍、悬浮窗以及实际需要的文件/麦克风权限；后台自启动和电池限制需要在系统设置中按机型开启。任何脚本都不能代替用户点击敏感系统授权。实现真正独立后台常驻仍需 AutoJs6 宿主保障或单独原生 Android 服务及真机验证。
