# 手机 Agent 使用说明

更新：原启动器检查更新 → 下载安装 → 重启。沿用 AutoJs6 的 jarvis_config_v2、Key、音色与 /sdcard/Jarvis/Memory/，无需再次导入程序。启动器保持 2.0。

## 语音与图像

默认单击蓝狐启动 MiMo 中转站录音转写，模型 mimo-v2.5-asr，沿用原大脑地址和 Key；不是鱼音的合成接口。安静约 0.9 秒结束，再点小人也可结束。录音和转写不弹卡片，可双击小人取消本次听写并打开文字输入；已开始上传的请求不能撤回。音频只在内存中组 WAV，不落盘。未检测到人声不上传。

更多设置仅保留听写方式、回答后自动朗读及核心目录。OPPO系统识别服务缺失，选择MiMo接口听写；原HTTP400仍未证明解决，不反复测试缺失系统入口，不静默切换收费服务。原Base64/Data URL配置沿用已有渠道记录。

点按“读屏”读取当前无障碍文字、控件位置与捕获时间，直接发送到当前模型分析；长按“读屏”截图并直接交视觉模型分析。两个入口均不弹预览编辑框。文字位置只对当时画面有效，自绘页面可能缺失，不能当成完整截图。输入卡和回复卡操作一致。

截图需系统共享授权，同次共享内复用；退出或系统停止共享后释放，不能绕过Android授权。取到画面即恢复浮层，之后可以继续操作手机；分析的是刚才捕获的一帧，不是你随后切换的界面。专用截图入口省去大脑转述请求，网关和视觉模型速度仍会影响等待。图片、文字发送到你配置的中转站。


## 文件与界面

默认工作目录 /sdcard/Jarvis/Workspace/。Agent工具和每日记忆默认启用，不再单设开关；一键权限入口按缺失项引导麦克风、悬浮、无障碍、通知、所有文件访问，安卓仍要求逐项确认。已授权项跳过；无障碍授权通常由系统保存，脚本不能自行强制开启或保证OPPO不回收服务。原生通知桥配对也从一键设置进入。

可说“在工作目录新建项目说明.txt”“读取并修改 /sdcard/Download/笔记.md”。支持共享存储的 UTF-8 文本新增/改写、目录列出、单文件回收和恢复；覆盖前读取并核对哈希，修改保留备份，恢复遇到后来修改会拒绝覆盖。历史在 /sdcard/Jarvis/AgentData/history/。不开放 shell，保护 Jarvis 程序及执行历史、Android/data 与 obb；不能绕过应用私有目录、Root/系统分区权限。不是所有二进制文件编辑器。

可说“打开微信”“点击某个可见控件”“输入这段草稿”。通过无障碍可见节点操作，遇到歧义会要求补充目标。最多连续八步，可在主面板停止任务。没有无障碍时会明确失败，不假称已执行。草稿提供独立复制，通知存在时可跳对应聊天，其他情况打开对应应用；最终发送、支付等由你确认。

图片、任务读取的相关文字、对话和记忆会发送到你配置的中转站。不把 API Key 写进公共包、日志或记忆；文件内指令与截图内容不作为新授权。

## 每日上下文与记忆

按手机本地日期记录 /sdcard/Jarvis/Memory/Daily/YYYY-MM-DD.jsonl，另有可供 Obsidian 浏览的 .md。重启恢复当天对话；模型窗口有限时自动装入近期片段，较早内容可由助手搜索，不承诺整天无限文本同时放入一次请求。

次日空闲时整理前一日；应用关闭时无法定时运行，下次启动补做。大日记分段并保留进度，完成后当天不重复执行。每日整理会调用你的对话模型，按中转站计费；当前按用户要求默认开启。当前日明确偏好也可即时记录。

实际使用文件是 User_Persona.md 和 人际关系表.md。自动区域用 HTML 注释标记，区域外手工内容保留；不要删掉半个标记。Relationship_Graph.json 保存带日期与原话依据的关系，Collaboration_Memory.json 保存明确/推测偏好，Daily/*.summary.json 保存摘要与恢复记录。明确事实需用户原话支持；推测不升级为已确认设定，无法自行提升权限。同类新偏好可替换旧偏好，文件并发修改会停止覆盖并稍后重试。

## 会话与简化入口

单击小人直接听写，不再先恢复旧卡片；录音中再单击结束，双击打开文字输入并取消本次听写。录音只显示偷听，转写/任务只显示思考或工作，最终回答或明确失败才弹结果卡。长按小人或点卡片“历史”，第一项“最近回复”可一键找回；也可按日期选择最近 100 条消息，完整记录仍在磁盘并支持搜索。切换历史后续聊追加到所选日；选择今天返回当前日，不删除日记。

气泡移除“朗读/停声”，普通回答按自动朗读设置播放。点击“读屏”读取无障碍文字和坐标后直接分析；长按截图直接交视觉模型，两者都不回填输入卡。系统/受保护画面限制仍存在。

## 多 API 渠道和模型

大脑连接 → 设置：渠道下拉框切换，每个渠道保留 URL、Key、当前对话模型、ASR 模型、可选视觉模型与封装设置。任务/录音/整理进行时不能切换渠道。原配置自动成为“原有渠道”，沿用原 Key。渠道名单位于原 AutoJs6 storages，不进入程序更新包；不是云同步或系统加密保险库。

“新增渠道”打开留空的名称、接口地址、API Key、对话模型四栏，填写后保存，在渠道下拉框选择使用；每栏有固定标签，不影响原渠道。另点“批量导入”展开原粘贴框，停顿后自动导入，不切换当前渠道。支持 JSON 数组或 {"channels":[...]}，字段 name、url/base_url、key/api_key、model、models、asr_model、vision_model。也支持每组依次四行：名称、HTTPS 地址、Key、对话模型，组间空行；模型可以稍后补。同一 URL + Key 去重，不同 Key 分开。不要把含 Key 的文本提交到公开仓库。管理支持改名、确认删除；当前渠道须先切到其他渠道才能删除。

对话模型下拉选择保存的候选；手动填写后“保存候选”，或“获取模型列表”调用当前渠道 GET /v1/models。网关不支持列表时继续手填；列表包含不等于账号可调用。候选按渠道 ID 隔离。

“测试对话模型”调用当前对话模型并在按钮下持续显示结果；“测试听写模型（录音）”录一句真实声音，以 ASR 配置调用，结果在自己的区域显示，不转交对话模型。两者不会误用同一段文本问候测试。测试会正常使用配置中的接口，不保证免费。

模型空白、只返回思考、空对象或“暂无内容”占位不再显示为成功；格式错误最多修正一次，仍失败显示模型及原因。UI 操作失败会保留执行器错误，不虚构“已给文件传输助手发送”。目前仍由用户确认最终发送。


## 正文与播放修复

正文只展示自然文本，不展示 answer/emotion 等 JSON 字段、动作请求或 XML 工具片段。解析支持模型错误放入字符串内的真实换行与二次编码；无法修复时最多请求格式修正一次，仍无效则明确报失败。模型自己写的目录清单或 tool_result 不是本机执行证据，不能据此声称已检查或清理文件。

系统朗读出错时直接保留完整文字，不从头逐字重打。Fish 在尚未播放前失败可回退一次；已经播放后再失败不换声音重读本段。文字范围回调不倒退，重复开始/过期动画忽略。修复程序的重复路径不等于保证安卓引擎或音频服务从不中断；实机仍需验收。文件修改所用 content 保留原格式，不受回复清洗影响。

## preview15 未发布候选

本分支新增可安装的原生通知桥，安装、授权、隐私与真机步骤见 [NATIVE_NOTIFICATIONS.md](NATIVE_NOTIFICATIONS.md)。原生应用与 AutoJs6 分开运行，脚本退出期间可由原生监听接收并保存实际系统通知；强停、撤销权限、系统后台限制仍可能漏收，不能称永远常驻。

未配套时仍由 AutoJs6 回调接收。两种模式都会先存本地队列，忙碌/听写/朗读只推迟分析和显示，不直接丢弃接收。notifications.recent 只查 Jarvis 已同步的实际记录，不是微信或 QQ 全量聊天。原生桥默认仅微信、QQ、钉钉，不扩展到其他社交应用。通知分析仍交给你选择的中转站，原生端本身不联网。

候选启动后仅清理 Jarvis/App 下符合命名的旧版本、旧下载缓存和多余状态备份；保留当前/上一版以及仍运行或较新的目录。链接和重定向跳过，版本指针变化停止。手动 Download/WeiXin ZIP、记忆与 Agent 数据不删除。

251 项 Node 回归、3 项原生主机检查及 APK 签名验证通过，不等于 OPPO 真机通过。手机在线通道保持 preview14，候选需手动安装验证。

## preview17 渠道、秘书汇报与提醒（候选）

大脑连接的新增表单可展开/收起；保存渠道后自动获取该渠道模型，手动刷新入口保留。管理在原页面里修改名称、接口和Key；删除需再点一次确认，先切换正在使用及被模型引用的渠道。眼睛按钮仅切换本机显示，不改变Key。Fish的Key位于Fish音色设置，不占大脑连接区域。

当前对话、视觉、语音识别各自点击右侧菜单，可搜索全部已知的“渠道·模型”并独立指定。已有ASR默认固定在原渠道，换对话渠道不会改听写。请求使用所选角色所属渠道的地址和Key；图片/音频可能发往不同服务商，请根据菜单标签选择。远端/models未公开的名称不会凭空推断能力，已列出也须实际测试；模型未配置或引用渠道失效会报错，不静默使用其他Key。

回答原文和复制内容保留网址与代码，朗读改为用途/摘要，不逐字符念长链接或代码。普通群聊仅保留记录；明确私信、提及你或重要事项才主动汇报。分类依据通知内容及模型判断，无法保证辨认所有私信/群聊。通知卡原消息仍可查看，草稿按钮用于复制与跳转，不自动发送。

重要且需要处理的消息默认30分钟后提示，最多两次、间隔两小时；点“不再提醒”停止。不能检测所有应用里的真实已读/已回复，提示只表示还没标记处理。可以直接说“明天下午三点提醒我回消息”，也可询问/取消已有日期提醒。所有本地提醒仅在Jarvis脚本运行且空闲时显示；停止后重开补查，不是系统闹钟。明确要求系统闹钟时仅尝试打开系统时钟设置页，需要你确认；手机未提供入口或宿主缺权限会明确失败。

查资料使用实际联网检索工具，不主动打开浏览器。当前来源为Bing公开RSS搜索，查询关键词会发给搜索服务，返回摘要与来源链接后再由对话模型整理。摘要不等于阅读全文/核实，重要信息应继续核对来源；服务不可用会报告失败，不假装已搜索。

## preview18 测试更新

通过原启动器检查GitHub更新、下载校验并安装、重启；无需USB或重填Key。历史入口改为自绘悬浮列表，编辑卡/键盘先收起，按日期和条目选择；点击外部收起，不用系统弹窗。

系统朗读改为先用原系统引擎合成完整音频，加真实静音前导后播放。试听和回答共用音色参数及播放流程；不按估算播放超时停止。文件合成或WAV不受支持时明确显示失败，实际开头/结尾效果仍需你试听。

静音2秒自动结束：未说话不上传，有效说话后的2秒停顿则转写并处理问题。转写没有文字不伪造回答。HTTP422明确拒绝input_audio类型时，只在同一URL/Key下做一次file兼容尝试，其他错误不反复上传；中转站未正确路由音频仍会失败。

回复不再附执行记录、零项文件更改等统计，默认省略不重要消息的噪音清单；真实失败会简要说明。新问题优先于旧故障和引用通知，较早当天对话保留在日志中按需检索；新任务会停止旧任务的后续动作，但已完成的修改不会自动撤销。
